# 大卡鹰眼 - 智能数据决策平台 (Daka Eagle Eye)

> 基于 Vue 3 + Vite 构建的智能数据查询与分析平台，支持自然语言查询、深度分析报告生成和数据下载功能。


### 环境要求

- Node.js >= 20.0.0
- pnpm >= 8.0.0
